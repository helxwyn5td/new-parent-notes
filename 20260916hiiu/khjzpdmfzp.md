# 科普视窗丨了解遗传代谢病—酪氨酸血症

> 更新时间：2026-09-16 (UTC+8)

SUMMER

Limit beauty      

**01**

酪氨酸是人体氨基酸的一种，一部分来源于食物、蛋白质分解，另一部分来源于体内某些氨基酸的转化。肝脏是人体蛋白质、氨基酸等物质代谢的重要场所，如果发现宝宝肝功能不好，在排除感染、药物等因素，要考虑遗传代谢病的可能性。

酪氨酸血症是氨基酸代谢障碍性疾病的一种，是由于酪氨酸分解代谢途径中酶的缺陷，导致血浆中酪氨酸明显增高，属于常染色体隐性遗传。根据酶缺陷的种类，分为3种类型。

**02**

**分型及临床表现**

I型 又称肝-肾型酪氨酸血症，是最常见的类型，由于延胡索酰乙酰乙酸水解酶（FAH）缺陷，引起肝、肾及周围神经病变为特征的代谢性疾病。又分为急性型、亚急性型、慢性型。急性型最常见，约占80%，多发生于生后几天至几周内发病，急性肝功能衰竭为主要表现，可见肝大、黄疸、贫血、初学倾向、厌食呕吐及生长缓慢，若不及时治疗，常在生后1岁以内死亡。亚急性和慢性一般在生后6个月-2岁发病，除肝损害外，还有肾小管及神经系统损害，如肝硬化、肾性糖尿、氨基酸尿、佝偻病、嗜睡等。慢性型患者在肝硬化基础上会逐渐进展为肝细胞癌。HT-I是肝癌风险最高的遗传代谢病。

II型 又称眼-皮肤型酪氨酸血症，是由于酪氨酸氨基转移酶（TAT）缺陷，导致角膜增厚、掌跖角化、发育落后为特征的代谢性疾病。

III型 是由于4-羟基苯丙酮酸双加氧酶（4-HPPD）缺陷，所致以神经精神症状为主要表现的临床综合征。

**诊断**

1. 实验室检测：血浆谷丙转氨酶、谷草转氨酶增高，甲胎蛋白增高，凝血功能异常，碱性磷酸酶增高，低血磷等。

2. 血氨基酸分析：酪氨酸（Tyr）、琥珀酰丙酮（SA）增高。

3. 尿有机酸分析：4-羟基苯乳酸、4-羟基苯乳酸、4-羟基苯丙酮酸、琥珀酰丙酮增高。

4. FAH等位基因致病突变分析，可确诊。

治疗

减少酪氨酸摄入，低苯丙氨酸、低酪氨酸饮食，药物（尼替西农）控制，必要时需进行肝移植治疗。

**预后及预防**

1.通过新生儿疾病筛查诊断的患儿，早期治疗，预后较好。如未经治疗患儿可出现肝衰竭、肝癌、生长发育迟缓等。

2.避免近亲结婚，患者父母再生育时可通过基因突变分析对胎儿进行产前诊断。
